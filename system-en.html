03

Trade Calculator

Position Size & R:R

How to use it

  • Define invalidation before position size.
  • Risk $ = balance × risk %.
  • Position size = risk $ / stop distance.
  • For a prop challenge, working risk should be well below the firm limit.
  • R:R does not replace setup quality.
For CFDs/FX also account for contract size, tick/pip value, commissions and swaps.

Telegram Trading Bot

Commands

  • /status — prop account + drawdown
  • /today — today's trades and PNL
  • /risk — personal / firm risk room
  • /open — open trades
  • /review — last-trade review
  • /weekly — weekly report

Security & activation

The webhook accepts only the configured Telegram chat. The bot token is never stored in GitHub or browser storage.

Rotate the token in BotFather first. Then add TELEGRAM_BOT_TOKEN, TELEGRAM_ALLOWED_CHAT_ID and TELEGRAM_WEBHOOK_SECRET in Supabase → Edge Functions → Secrets. Do not paste the new token into chat.
