Senior Trader Software Architecture · 2026

Trading System Hub: market, risk, cloud, AI and Telegram in one place.

A personal trading operating system rather than a signal service: Binance market data, TradingView-style charting, position sizing, prop limits, journal, screenshots, Supabase knowledge base, a free local analyst, Telegram commands and an architecture ready for external AI APIs.

The system can improve process discipline and risk visibility, but it cannot guarantee profit. Its job is to reduce operational mistakes, protect capital and create measurable evidence.

Trade Calculator

Position Size & R:R

How to use it

  • Define invalidation before position size.
  • Risk $ = balance × risk %.
  • Position size = risk $ / stop distance.
  • For a prop challenge, working risk should be well below the firm limit.
  • R:R does not replace setup quality.
For CFDs/FX also account for contract size, tick/pip value, commissions and swaps.

07

Telegram Trading Bot

Commands

  • /status — prop account + drawdown
  • /today — today's trades and PNL
  • /risk — personal / firm risk room
  • /open — open trades
  • /review — last-trade review
  • /weekly — weekly report

Security

The webhook accepts only the configured Telegram chat. The bot token is never stored in GitHub.

Because a bot token was posted in chat, rotate it in BotFather before production use and store the new token only in Supabase Edge Function Secrets.
