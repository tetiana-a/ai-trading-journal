# 02 — Technical Analysis

## Moving averages

A moving average can help visualize direction and dynamic trend context.

Example used during practice:

- **SMA 30**

It should not be treated as a standalone entry trigger.

## RSI

A basic interpretation used in study exercises:

- RSI above ~70 → overbought context.
- RSI below ~30 → oversold context.

Important: overbought does **not** automatically mean sell, and oversold does **not** automatically mean buy. Strong trends can remain extended for a long time.

## MACD

MACD can be used to observe:

- momentum changes,
- signal-line interaction,
- trend acceleration/deceleration,
- possible divergence.

## Divergence

Divergence is useful as supporting evidence, especially near an important level, but should be combined with structure and price action.

## Practical setup checklist

Before a technical trade:

1. Determine trend.
2. Mark important support/resistance.
3. Identify the active market structure.
4. Check candle behavior at the level.
5. Use RSI / MACD only as confirmation.
6. Define invalidation before entry.
7. Calculate risk/reward.
8. Avoid forcing a trade when confirmations conflict.

## Two-scenario thinking

For every setup, write two scenarios:

### Bullish scenario
What must happen for the long thesis to remain valid?

### Bearish scenario
What must happen for the short thesis to remain valid?

This reduces emotional attachment to one prediction.
