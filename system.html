Senior Trader Software Architecture

Trading System Hub: данные, график, AI, Telegram и prop-risk.

Цель — один центр: сделки из Trading Journal сохраняются в Supabase, рыночные данные приходят бесплатно из Binance, график строится на TradingView Lightweight Charts, AI делает post-trade review, Telegram получает алерты и отчёты, а prop-модуль контролирует drawdown до того, как ты нарушишь правила challenge.

01

Архитектура

Journal UIсделки, screenshots, stats
Binanceprice + candles + websocket
SupabasePostgres + Auth + knowledge
AI LayerOpenAI / Claude / Groq
Telegramalerts + commands + reports
Prop Guarddaily loss + max loss + targets
Принцип: браузер получает только public/publishable credentials. Telegram token, OpenAI/Anthropic API keys и любые secret/service-role ключи должны жить только в backend/Edge Functions.
02

Бесплатный профессиональный график

Binance public market data · API key не нужен
График использует бесплатную open-source библиотеку TradingView Lightweight Charts, а свечи — публичный Binance REST + WebSocket. Это не требует Binance API key для чтения рынка.

На сайте используется только Supabase publishable key + Supabase Auth. Row Level Security делает так, чтобы пользователь видел только свои записи.

04

Telegram Trading Bot

Команды

  • /status — баланс, equity, текущий drawdown
  • /today — PNL за день и число сделок
  • /risk — сколько ещё можно потерять до личного daily stop
  • /open — открытые сделки
  • /review — AI-разбор последней сделки
  • /weekly — недельный отчёт

Автоматические уведомления

  • достигнут 50% личного daily stop
  • 2 losses подряд → STOP DAY
  • цена пришла к alert level
  • закрыта сделка → PNL + screenshot + lesson
  • приближение к prop daily/max loss
  • ежедневный и недельный отчёт

Bot token хранится в Supabase Edge Function secrets, не в GitHub Pages.

05

AI: ChatGPT + Claude + Groq

AI Trade Review

После закрытия сделки backend собирает: структуру сделки, PNL, emotion, entry/exit reason, prop limits, рыночный контекст и последние записи knowledge base. AI возвращает: что сделано правильно, нарушение правил, качество сетапа, риск и один конкретный урок.

Важно про подписки

Подписка ChatGPT Plus/Pro и подписка Claude дают доступ к продуктам ChatGPT/Claude, но обычно не являются API-балансом для твоего сайта. Для автоматического вызова моделей из Trading Journal нужны отдельные API credentials/billing у соответствующего API-провайдера. Пока можно оставить Groq как бесплатный/дешёвый fallback и подключить OpenAI/Anthropic позже через Edge Function.

06

Prop Risk Engine

Что считает автоматически

  • current daily PNL
  • remaining personal daily risk
  • remaining firm daily loss
  • remaining max loss
  • distance to profit target
  • loss streak
  • best day / consistency metrics

Режим challenge

Рабочий risk budget должен быть меньше лимита prop firm. Например, при firm Daily Loss 3% система может блокировать новые сделки уже после личного -1% или после 2 убытков подряд.

Это risk-control и аналитическая система, а не автоматический исполнитель сделок. Автовыставление ордеров на prop-account следует подключать только если конкретная фирма и платформа явно разрешают такой тип automation.
