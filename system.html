03

Trade Calculator

Position Size & R:R

Логика использования

  • Сначала определяется invalidation, только потом размер позиции.
  • Risk $ = balance × risk %.
  • Position size = risk $ / stop distance.
  • Для prop challenge рабочий риск должен быть заметно меньше firm limit.
  • R:R не заменяет качество сетапа: target должен быть структурно реалистичен.
Калькулятор считает базовую модель. Для CFD/FX дополнительно учитывай contract size, tick/pip value, commission и swap конкретной платформы.

Telegram Trading Bot

Команды

  • /status — prop account + drawdown
  • /today — сделки и PNL за день
  • /risk — personal / firm risk room
  • /open — открытые сделки
  • /review — разбор последней сделки
  • /weekly — недельный отчёт

Безопасность и активация

Webhook принимает команды только из разрешённого Telegram chat. Bot token не хранится ни в GitHub, ни в браузере.

Сначала перевыпусти token через BotFather. Затем добавь TELEGRAM_BOT_TOKEN, TELEGRAM_ALLOWED_CHAT_ID и TELEGRAM_WEBHOOK_SECRET в Supabase → Edge Functions → Secrets. Новый token в чат не присылай.
Ожидаю безопасные Secrets.
