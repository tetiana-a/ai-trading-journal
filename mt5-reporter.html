Советник для твоего журнала

MT5 собирает закрытые позиции в файл. Ты импортируешь его в журнал, а журнал сохраняет записи в твой аккаунт Supabase. Советник не открывает сделки, не меняет стопы и не запрашивает пароль.

Что уточнено в твоём плане

ВопросПрактический вывод
MT5, MT4 или cTrader?Для выбранного MT5-счёта удобен MQL5-репортёр. cTrader имеет официальный Open API для отдельной интеграции. Преимущество зависит от счёта и способа подключения, а не от обещаний доходности.
Советник = автоторговля?Нет. Этот файл только читает историю и записывает CSV. DLL, WebRequest и торговые разрешения ему не нужны.
Одно исполнение = одна позиция?Не всегда. Частичные исполнения агрегируются по идентификатору позиции; выгружаются только полностью закрытые позиции. Развороты пропускаются.
Терминал выключен?Файл не обновляется. После запуска заново читается доступная история с HistoryFrom. Полнота зависит от истории, которую вернул брокер.
Стабильная прибыль?Репортёр помогает учёту, но не проверяет качество стратегии и не гарантирует прибыль или соблюдение проп-лимитов.

Установка: шаг за шагом

  1. Начни с демо / Free Trial. Открой настольный MetaTrader 5 от твоего брокера. Этот файл не подходит для MT4, мобильного приложения или веб-терминала.
  2. Скачай файл выше. В MT5 выбери File → Open Data Folder → MQL5 → Experts. Скопируй туда TK_Journal_Reporter.mq5.
  3. Скомпилируй. Нажми F4, открой файл в MetaEditor и нажми F7 / Compile. Продолжай только если внизу указано 0 errors. Если есть ошибка — сохрани её текст; файл .ex5 вручную переименовывать не нужно.
  4. Добавь на один отдельный график. В MT5 открой Navigator → Expert Advisors → Refresh. Перетащи TK_Journal_Reporter на свободный график. Достаточно одного экземпляра на счёт, любой инструмент. Не заменяй им уже работающего торгового советника.
  5. Настрой период. HistoryFrom — начало нужной истории, по умолчанию 01.01.2020. RefreshSeconds — интервал обработки изменений, по умолчанию 60 секунд, минимум 10. Для CSV включать Algo Trading, DLL или WebRequest не требуется.
  6. Дождись выгрузки. В течение интервала на графике появятся имя файла, число экспортированных и пропущенных позиций. При переключении счёта удали и заново прикрепи репортёр.
  7. Найди CSV. File → Open Data Folder → MQL5 → Files → MT5_Journal_НОМЕРСЧЁТА.csv. Не редактируй и не открывай файл в Excel во время записи.
  8. Импортируй в журнал. Открой «Новая сделка», войди по email в свой аккаунт и нажми «Импорт Broker CSV». Выбери файл. Записи сохраняются в Supabase через существующий импорт. Файл на компьютере сам на сайт не отправляется.
  9. Сверь одну позицию. Сравни инструмент, направление, лоты, цены, дату и Net PNL с историей MT5. Проверь валюту счёта. Повтори импорт того же неизменённого файла — повторных строк быть не должно.

Что входит в расчёт

Одна строка — полностью закрытая позиция. Цены входа и выхода взвешены по объёму; объём — суммарные лоты входов. Net PNL = сумма DEAL_PROFIT + DEAL_COMMISSION + DEAL_SWAP + DEAL_FEE по связанным исполнениям. Отдельные балансовые корректировки и комиссии без привязки к позиции не включены: сверяй итог с отчётом брокера.

Даты CSV — время сервера брокера без подтверждённого часового пояса. Не используй импорт как доказательство дневных лимитов FTMO. Открытые и частично закрытые позиции, развороты, неподдерживаемые операции и позиции, открытые до HistoryFrom, пропускаются. Стопы, тейки и фото эта версия не восстанавливает.

Повторный импорт идентичного файла не создаёт дубликаты. Не переименовывай CSV. Если брокер исправил старые исполнения, сначала сверяй историю: текущий импорт не является системой автоматического исправления прежних записей.

Если что-то не работает

  • Нет файла: проверь вкладку Experts, подключение и правильную папку данных терминала.
  • Exported: 0: нет поддерживаемых полностью закрытых позиций в выбранном периоде.
  • Skipped: больше нуля: открытые, неполные или неподдерживаемые позиции намеренно не превращены в вымышленные результаты.
  • Не видно в Navigator: проверь успешную компиляцию и папку именно этого терминала.
  • Ошибка импорта: войди по email; не изменяй заголовки и имя CSV.

Перед автоматическим подключением

Для прямой отправки потребуется отдельный отзывной ключ, привязанный к твоему пользователю и счёту, серверный приёмник, защита от дублей и повторная доставка. Общий ключ для всех пользователей использовать нельзя. Ключ репортёра должен быть и в терминале: утверждение «все ключи только на сервере» к такому подключению неприменимо. Ключ Supabase service_role нельзя помещать в советник или публичный сайт.

При сетевой версии обработчик OnTradeTransaction только отмечает изменения; отправка выполняется отдельно по таймеру. WebRequest синхронный и не работает в Strategy Tester. Для этой CSV-версии сеть не используется.
